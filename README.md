# Improving Robustness of Mathematical Reasoning in LLMs with Richer Chain-of-Thought Prompting

Archived final project for UCSD's CSE 256 (Statistical Natural Language Processing) with Dr. Ndapa Nakashole.
Built upon the work of [Mirzadeh et al's *GSM-Symbolic: Understanding the Limitations of Mathematical Reasoning in Large Language Models* (2024 arXiv preprint)](https://arxiv.org/abs/2410.05229).
See [`report.pdf`](report.pdf) for results and discussion.
